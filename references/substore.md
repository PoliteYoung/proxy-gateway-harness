# Sub-Store Traceability

Use one independent source for each authority such as ARM AGSBX, x86 AGSBX, x-ui, and custom Xray. Preserve these stages:

1. Running server configuration
2. Raw source
3. Sub-Store source
4. Collection aggregation
5. URI, sing-box, and Mihomo artifacts
6. Public cache-bypassed download

Assign a stable non-secret fingerprint to every normalized connection. Compare SNI, ALPN, transport, TLS/Reality, Flow, Encryption presence, path, host, and IP version across stages. Never deduplicate only by name, host, or port. Report unsupported target formats instead of silently dropping nodes.

Keep candidate and live collections separate. Publication must be an atomic pointer or file replacement with a tested rollback target.
